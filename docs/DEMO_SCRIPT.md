# Demo Script (60–90 Seconds)

## Act 1: The Hook (0–15s)
* *"Most web maps show you what currently exists. AFTERWEB shows you where the early web tried to go—including the roads that no longer lead anywhere."*
* Open the 3D City view showing 3 historical districts with glowing amber routes.

## Act 2: Following an Observed Link (15–35s)
* Select a building (e.g. Space Jam 1996 or early directory).
* Click an observed hyperlink route extracted from the page.
* Camera smoothly glides along the route.

## Act 3: The Ghost Plot (35–55s)
* The route terminates at an empty, outlined lot: a **Ghost Plot**.
* Inspector shows: *"No capture found in checked archive query"*, original anchor text, and target URL.
* Emphasize: We never hallucinate or invent lost pages.

## Act 4: Evidence-Bound Local AI & Citations (55–75s)
* Ask: *"What do we know about this missing destination?"*
* The local Qwen3 model answers using source page context and attaches `[E1]` citation chips.
* Click citation: the exact text chunk from the original page highlights in the evidence drawer.

## Act 5: Offline Proof (75–90s)
* Toggle offline indicator / disconnect Wi-Fi.
* Re-run an evidence query.
* Everything runs 100% on localhost—proving privacy and preservation without cloud dependencies.
